دار حصة 3253 | طريقة النشر

1) أنشئ حساباً على https://supabase.com وأنشئ مشروعاً جديداً.
2) افتح SQL Editor، والصق محتوى supabase_setup.sql ثم Run (نفّذه مرة واحدة فقط).
3) من Project Settings > API (أو Connect) انسخ Project URL و anon/publishable key إلى config.js. لا تستخدم secret/service_role key.
4) في Authentication > URL Configuration ضع رابط موقع Vercel النهائي في Site URL وأضفه إلى Redirect URLs. ويمكنك مؤقتاً إضافة رابط المعاينة.
5) ارفع ملفات هذا المجلد إلى مستودع GitHub خاص بك، ثم افتح https://vercel.com > Add New > Project > Import Git Repository > Deploy. الإعداد Static، ولا يحتاج Build Command. يمكن استخدام واجهة Vercel لرفع المشروع عبر GitHub.
6) بعد ظهور الرابط، افتح الموقع وسجّل الدخول بالبريد الإلكتروني. افحص بريدك واضغط رابط الدخول.
7) عيّن المالك: من Supabase SQL Editor نفذ سطر UPDATE الموجود آخر supabase_setup.sql بعد استبدال البريد ببريد المالك الذي سجل الدخول بالفعل.
8) حدّث الصفحة؛ تظهر لوحة المالك. أرسل رابط الموقع للعائلة.

تنبيهات:
- بدون Supabase والإعدادات أعلاه لن تعمل الحجوزات المشتركة.
- أسماء الحاجزين ظاهرة لكل أفراد العائلة الذين سجلوا الدخول.
- كل طلب أصفر يحجز الأيام مؤقتاً حتى يوافق المالك أو يلغيه؛ الإلغاء يعيد الأيام للإتاحة.
- الإلغاء لا يحذف السجل. كل مستخدم مسجل يستطيع تقديم طلب. لاقتصار الدخول على العائلة فقط، يجب إضافة قائمة سماح بالبريد الإلكتروني على مستوى قاعدة البيانات/التسجيل قبل النشر العام.
- اختبر الموقع بحسابين مختلفين قبل إرسال الرابط إلى العائلة.
- الباقة المجانية وحدودها وسياسات مزودي الخدمة قابلة للتغيير.
